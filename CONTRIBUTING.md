# Contributing to Panic Mode

We welcome contributions that improve the defensive and educational quality of this repository.

## Guidelines
1. **No New Attack Techniques:** We do not accept PRs that introduce new destructive payloads, malware, persistence, or evasion techniques not covered by the scope of this project.
2. **Defensive Focus:** Contributions should focus on improving the Detection, Mitigation, and Recovery sections.
3. **Format:** Follow the standard markdown format used across the repository.
4. **Review:** All changes must be manually reviewed to ensure they do not introduce unintended harmful consequences.
